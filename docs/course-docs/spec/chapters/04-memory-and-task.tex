\section{地址空间与权限}
基础实现采用 Sv39 与 4 KiB 页。用户空间位于低半区，内核映射位于高半区；用户与内核必须隔离。运行期页表可采用共享高半内核映射或独立内核页表加 trampoline 的方案。
